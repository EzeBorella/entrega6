
Taller Mecanico Integral Multimarca
Descripción del proyecto

Este proyecto consiste en el desarrollo de un sitio web para un Taller Integral Multimarca, destinado a presentar el taller, mostrar sus instalaciones y dar a conocer sus servicios de mecánica automotriz, mantenimiento y reparación de vehículos.

El sitio cuenta con una interfaz visual, un menú de navegación y diferentes secciones para facilitar el acceso a la información del taller.

Características
Inicio: presentación del taller y sus instalaciones.
Servicios: sección dedicada a los servicios ofrecidos.
Nosotros: información sobre el taller.
Historia: sección destinada a contar la trayectoria del taller.
Contacto: sección para facilitar la comunicación con los clientes.
Diseño adaptable: menú de navegación responsive mediante Bootstrap.
Animaciones: efectos visuales al desplazarse por la página.
Redes sociales: enlaces a Facebook, Instagram y X.
🛠️ Tecnologías utilizadas
HTML5: estructura y contenido del sitio web.
SCSS: estilos y diseño personalizado.
Bootstrap 5: componentes y diseño responsive.
Google Fonts (Poppins): tipografía del sitio.
AOS (Animate On Scroll): animaciones al desplazarse por la página.
